# Bóveda de ejemplo

Bóveda de demostración construida con la estructura de `vault-template/`. **Todas las personas, proyectos y datos son ficticios.**

Ábrela en Obsidian (*Open folder as vault* → `examples/example-vault`) para explorar:

- El grafo de enlaces entre proyecto, reunión, persona, área y notas permanentes.
- Los backlinks de [[Taller de Python]].
- El mapa de contenido [[MOC - Aprendizaje]].
- La nota diaria [[2026-11-16]].
- La memoria para agentes en [[contexto-activo]].

Para probar los agentes sobre ella, copia también `AGENTS.md` y `99-SYSTEM/` desde `vault-template/`, o trabaja sobre una copia creada con `scripts/new-vault.py` y añade estas notas.
