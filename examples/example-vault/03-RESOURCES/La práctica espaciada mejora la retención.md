# La práctica espaciada mejora la retención

Repartir el estudio de un tema en varias sesiones separadas en el tiempo produce mejor recuerdo a largo plazo que concentrar el mismo tiempo en una sola sesión. Cada repaso llega cuando el recuerdo empieza a debilitarse, y recuperarlo en ese momento lo refuerza.

## Por qué importa
Planificar repasos cortos durante varias semanas es más eficaz que estudiar todo la víspera.

## Relaciones
- Se combina con [[La recuperación activa supera a la relectura]]: cada repaso debería ser un ejercicio de recuerdo.
- Se aplica en [[Temario por sesión]], donde cada sesión repasa las anteriores.
