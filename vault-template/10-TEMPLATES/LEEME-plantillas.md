# Plantillas

Plantillas del plugin oficial *Templates* de Obsidian. Inserta una con la paleta de comandos: **Templates: Insert template**.

| Plantilla | Uso |
| --- | --- |
| `daily-note` | Nota diaria (se aplica sola con *Daily notes*). |
| `project` | Nota principal de un proyecto. |
| `meeting` | Acta de reunión. |
| `person` | Nota de una persona. |
| `permanent-note` | Nota permanente. |
| `learning-note` | Notas de curso, libro o tema de estudio. |
| `idea` | Idea en incubación. |

Variables disponibles: `{{title}}`, `{{date}}`, `{{time}}` y formatos como `{{date:YYYY-MM-DD}}`.

No escribas notas reales en esta carpeta.
