# Sesiones de agentes

Un archivo por sesión importante con un agente de IA: `YYYY-MM-DD-tema.md`.

Cada resumen incluye: objetivo, cambios realizados (con rutas), decisiones y pendientes. Ver `99-SYSTEM/rules/agent-behavior.md`.

Una vez al mes, resume las sesiones antiguas en `09-AI-MEMORY/decisiones.md` y muévelas a `04-ARCHIVE/`.

> En el repositorio de plantilla, el contenido de esta carpeta está excluido de Git (salvo este archivo). En tu bóveda privada puedes decidir si versionarlo.
