# Registro de decisiones

Decisiones importantes y su motivo, para que cualquier agente (y tu yo futuro) entienda por qué las cosas son como son. Añade las nuevas arriba.

## Formato

```markdown
### YYYY-MM-DD — Título de la decisión
- **Contexto:** qué problema había.
- **Decisión:** qué se decidió.
- **Alternativas descartadas:** y por qué.
- **Relacionado:** [[Proyecto o nota]]
```

## Decisiones

### 2026-11-16 — Adoptar la estructura PARA con bandeja de entrada
