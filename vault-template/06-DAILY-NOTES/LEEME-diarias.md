# Notas diarias

Una nota por día, `YYYY-MM-DD.md`, creada con el plugin oficial *Daily notes* y la plantilla `daily-note`.

## Para qué
- Registro rápido de lo que haces, aprendes y piensas.
- Capturas del día (que luego se procesan).

## Regla
El conocimiento duradero no se queda aquí: extráelo a una nota permanente en `03-RESOURCES/` y deja un enlace.
