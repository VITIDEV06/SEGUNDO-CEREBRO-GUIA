# Taxonomía de tags

Los tags expresan **temas transversales**. El estado de una nota va en la propiedad `estado`, no en un tag. El tipo va en la propiedad `tipo`.

## Reglas

1. Todos los tags en minúsculas, sin tildes y con guiones: `#tema/gestion-del-tiempo`.
2. Máximo dos niveles: `#tema/subtema`.
3. Máximo cinco tags por nota.
4. Antes de crear un tag nuevo, revisa esta lista. Si lo creas, añádelo aquí.

## Prefijos

| Prefijo | Uso | Ejemplos |
| --- | --- | --- |
| `tema/` | Disciplina o materia | `tema/programacion`, `tema/aprendizaje`, `tema/productividad` |
| `formato/` | Tipo de fuente | `formato/libro`, `formato/articulo`, `formato/video`, `formato/curso`, `formato/conversacion-ia` |
| `contexto/` | Ámbito de la vida | `contexto/trabajo`, `contexto/estudios`, `contexto/personal` |
| `revisar/` | Requiere acción de mantenimiento | `revisar/verificar-fuente`, `revisar/dividir`, `revisar/enlazar` |
