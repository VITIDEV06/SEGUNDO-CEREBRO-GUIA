# Ejemplos de sesiones con agentes

Ejemplos ilustrativos de **petición → respuesta del agente → resultado**. Muestran el comportamiento esperado según las reglas de `AGENTS.md`; no son transcripciones literales de una herramienta concreta, y la redacción exacta de cada agente variará. Todos los datos son ficticios.

| Ejemplo | Muestra |
| --- | --- |
| [Recuperar contexto con trazabilidad](sesion-recuperar-contexto.md) | Respuesta con rutas, y cómo el agente declara lagunas en lugar de inventar. |
| [Petición que el agente debe rechazar](sesion-limites-y-permisos.md) | Cómo responden las reglas y los permisos ante una edición en `05-PERSONAL/` y un borrado. |

Para ver archivos antes y después de un workflow, consulta [examples/example-workflows/](../../examples/example-workflows/README.md).
